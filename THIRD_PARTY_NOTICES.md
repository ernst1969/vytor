# Third-party notices

## MuscleMap body diagram geometry

`assets/muscles/body-paths.json` contains the male/female front/back outlines by Melih Colpan (MuscleMap), obtained through openGym's documented conversion of the original Swift path data to JSON, with subgroup shapes omitted. Vytor uses the geometry with its own React Native renderer and exercise-to-muscle mapping.

Sources:
- https://github.com/melihcolpan/MuscleMap
- https://github.com/arvids-unavailable/openGym/blob/main/frontend/src/lib/body-paths.js
- https://github.com/arvids-unavailable/openGym/blob/main/NOTICE.md
